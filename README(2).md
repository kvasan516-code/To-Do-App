# TaskFlow — To-Do List Web App

A responsive, premium **To-Do List Web App** built with HTML, CSS and Vanilla JavaScript.

## ✦ Design

The interface uses an editorial-style hero page before the task workspace:

- Large animated **Playfair Display** hero typography
- Clean **DM Sans** supporting typography
- Staggered entrance animations
- Floating background accents
- Subtle paper/noise texture
- Premium rounded workspace cards
- Bento-style progress statistics
- Responsive mobile layout
- Reduced-motion accessibility support
- No AI-generated imagery or unnecessary visual clutter

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- All / Active / Completed filters
- Completion percentage
- Progress ring
- Task statistics
- Clear completed tasks
- Browser `localStorage` persistence
- Responsive desktop, tablet and mobile design

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Browser `localStorage`
- Google Fonts: Playfair Display + DM Sans

todo-list/

## Run

No installation or build process is required.

Open `index.html` directly in a modern browser.

For development, open the project in VS Code and optionally use Live Server.

## Storage

Tasks are saved locally in the browser under:

```text
taskflow-tasks-v1
```

Refreshing the page will not remove your tasks.

## Responsive Breakpoints

The design adapts automatically for:

- Desktop
- Tablet
- Mobile

The sidebar becomes a top progress section on smaller screens and the task input changes to a stacked layout on narrow phones.

## Accessibility

The page includes:

- Semantic sections and navigation
- Accessible button labels
- Keyboard-friendly controls
- `prefers-reduced-motion` support
